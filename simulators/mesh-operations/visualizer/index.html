ABOUT THIS DEMONSTRATION

What the AVIAN simulator actually does

This application plays a deterministic trace generated by the Rust mesh-sim crate. The browser renders state returned by the local simulator API; it does not invent node counts, connectivity, mission synchronization, or recovery results.

01

Radio onboarding through CHUD

The opening sequence models a radio entering the management network. Operators can edit network ID, RF band, center frequency, channel width, transmit power, beacon period, and encryption. The local CHUD model validates, applies, and reads the simulated configuration back without writing hardware.

GET /api/radio/devices → GET /snapshot → POST /apply → POST /confirm
02

Leaderless mesh behavior

AVIAN creates authenticated ground and aircraft identities, observes peer links, synchronizes durable mission state, and measures connected components without assigning a permanent leader.

03

Failure and recovery

The detailed four-node trace removes the ground path, degrades a link, selects a failover path, drops an aircraft, and then reconciles state after recovery. Metrics are read from the resulting in-memory network state.

04

Executed 200-aircraft scale run

A separate in-memory run instantiates 200 aircraft and one GCS. Three trace states show the complete spider-web topology, ground and 20-aircraft loss with changed active paths, and all 201 nodes recovering onto mission generation two.

WHAT IS REAL IN THIS DEMO

Rust state transitions, topology planning, connected-component calculations, mission-record convergence, failure injection, recovery checks, and the 200 simulated aircraft nodes shown on screen.

WHAT IS SIMULATED

CHUD responses, PEAT-style transport behavior, aircraft flight stacks, radio discovery, link quality, latency, and command delivery all run as deterministic software models.

NOT YET VALIDATED

This is not 200 independent processes or radios. RF propagation, radio firmware, physical aircraft, real CHUD/PEAT services, field latency, interference, and hardware performance remain pending validation.
